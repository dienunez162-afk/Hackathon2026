Mapa de la Misión Lunar

Los 14 días de la base lunar como un grafo ponderado. Cada nodo es una situación del juego; las barras (radiación, energía, comida y salud) viven en el estado del jugador. En dos puntos de evaluación el juego revisa las barras y manda al jugador por la rama Experto, Normal o Rescate. El niño aprende jugando: cada concepto es una regla que ve funcionar, se vuelve una carta que puede usar, y reaparece en llamadas donde predice y actúa, en averías que diagnostica con pistas y en el manual que le deja al siguiente capitán.

El grafo

Ruta de la misión, día por día

Toca un nodo para ver qué pasa ahí. Las líneas punteadas son condiciones de las evaluaciones; los porcentajes son el peso de cada camino cuando hay dos eventos posibles.

En pantallas angostas el grafo se desliza hacia los lados.

Retos en la partida

Aprender sin que se sienta examen

Nada de trivia. El niño usa lo que sabe para salvar su base: predice qué va a pasar, decide qué hacer, diagnostica averías con pistas y usa cartas en el momento justo. La explicación solo aparece cuando se equivoca, y en una línea.

Simulador de balance

¿Qué tan difícil es la misión?

Simula partidas con las reglas de los archivos. La habilidad es la probabilidad de ganar cada minijuego. La comprensión es la probabilidad de entender y aplicar un concepto: predecir bien, elegir la acción correcta, diagnosticar una avería o usar una carta a tiempo. Cada partida nueva recuerda los temas, repasos y cartas del manual de la anterior, como pasaría con el mismo niño.

Cómo se mueve el jugador por el grafo

Las cuatro barras

Si una barra llega a 0 (o la radiación a 100) en cualquier día, la partida termina en evacuación.

Consumo de cada día

Se aplica al terminar cada día. De día los paneles recargan un poco; al ocultarse el Sol la energía empieza a bajar.

Qué significan las aristas

  • días: cuánto avanza el reloj. Toda ruta suma exactamente 14.
  • peso: probabilidad de tomar ese camino cuando hay dos eventos posibles el mismo día. Las salidas de un nodo suman 1.
  • condición: solo en los nodos de evaluación. El juego toma la arista cuya condición se cumple.
  • peso dinámico: el peso puede cambiar con datos reales. Ejemplo: si DONKI reporta llamaradas fuertes esa semana, sube la probabilidad de la tormenta sorpresa.

Evaluaciones

  • Experto: las 4 barras en verde. Retos más difíciles y más tareas de Control de Misión.
  • Normal: ninguna barra en rojo, pero no todas en verde.
  • Rescate: al menos una barra en rojo. Control de Misión ayuda, hay más calma y los retos son más fáciles.
  • Ocurren al final del día 4 y al final del día 10, cuando cae la noche lunar.

El nivel se ajusta solo, no se pregunta la edad

  • Libre: empieza en nivel 2 y se calibra con los primeros 3 retos. Salón: el maestro pone el grado y el nivel inicial sale de ahí.
  • Después sube con 4 de 5 retos bien y baja con 1 o ninguno. El niño nunca ve su nivel.
  • Nivel 1: frases cortas, consecuencias inmediatas, pistas explícitas.
  • Nivel 2: párrafos breves, términos STEM, consecuencias a dos pasos.
  • Nivel 3: datos y términos técnicos, consecuencias a largo plazo, hay que inferir.
  • El nodo trae el ejemplo de los tres niveles.

Estructura de los datos

Todo lo que ves en esta página sale de grafo-mision-lunar.json y retos-mision-lunar.json, y las partidas las corre simulador-mision.js. Estos son sus tipos:

type Barra = "radiacion" | "energia" | "comida" | "salud";
type Efectos = Partial<Record<Barra | "mision" | "barraMasBaja", number>>;

interface Nodo {
  id: string;                       // "N-D6"
  tipo: "inicio" | "evento" | "tarea" | "decision" | "control_mision"
      | "calma" | "evaluacion" | "final";
  fase: 0 | 1 | 2 | 3 | null;
  dia: number | null;               // 0 a 14 (null en evacuaciones)
  rama: "todas" | "experto" | "normal" | "rescate";
  reto?: 1 | 2 | 3;                 // dificultad del minijuego
  titulo: string;
  mensaje: string;                  // lo que dice Control de Misión
  minijuego: string | null;
  resultado: {
    exito?: Efectos; fallo?: Efectos;            // minijuegos
    opciones?: { texto: string; efectos: Efectos }[];  // decisiones
    siempre?: Efectos;                            // calma
  };
  niveles?: Record<"nivel1" | "nivel2" | "nivel3",
            { texto: string; decision: string; pista: string }>;
  informe: Informe | null;          // reemplaza al "¿Sabías que...?"
}

interface Arista {
  desde: string; hacia: string;
  dias: number;                     // 0 o 1
  peso: number;                     // probabilidad
  condicion?: "experto" | "normal" | "rescate"
            | "tres_estrellas" | "dos_estrellas" | "una_estrella";
  pesoDinamico?: string;
}

// Cada nodo deja un informe que entra a la bitácora
interface Informe { tema: Tema; texto: string; fuente: string | null }

// retos-mision-lunar.json
type Tema = "radiacion" | "polvo_lunar" | "sismos" | "micrometeoritos" | "noche_lunar"
          | "hielo_agua" | "invernadero" | "agua_reciclaje" | "energia_solar" | "salud_astronauta";
type Nivel = "1" | "2" | "3";

interface Carta {                   // una por tema; se desbloquea con su informe
  id: string;                       // "C-radiacion"
  nombre: string; frase: string;    // ícono + una línea
  uso: { tipo: "escudo" | "recurso"; barra: Barra; valor?: number; soloDeDia?: boolean };
  momento: string;                  // para emparejar en el manual del siguiente capitán
}

interface Situacion {               // llamada de Control de Misión
  id: string; tema: Tema;
  aviso: Record<Nivel, string>;
  prediccion: { pregunta: string; barra: Barra; cambio: "sube" | "baja" };
  acciones: { texto: string; efectos: Efectos }[];   // se muestran las primeras 2, 3 o 4
  correcta: number;
  explicacion: Record<Nivel, string>;              // solo si se equivoca
}

interface Averia {                  // diagnóstico con pistas
  id: string; temas: Tema[]; fases: number[]; barra: Barra;
  alarma: string;
  pistas: { clave: string[]; distractores: string[]; enganosa: string };
  acciones: string[];               // se muestran las primeras 2, 3 o 4
  correcta: number;
  explicacion: string;              // la da la Dra. Ortiz al resolverla
}
