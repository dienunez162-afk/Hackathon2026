## Cómo correr los tests

```bash
npm test
```

- `pruebas/banco.test.js`: banco válido (ids únicos, 3+ opciones, índice, fuente y URL NASA), rotación sin azar, repaso con otra variante, bitácora que rota, transferencia.
- `pruebas/texto.test.js`: ningún informe sale con texto roto al marcar las palabras del Diccionario.
